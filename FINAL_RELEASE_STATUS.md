## Important npm point

A fake lockfile must not be created. The real `frontend/package-lock.json`
must be generated by npm on a machine with registry access.

Run:

```bash
./scripts/final-local-qa.sh
```

This performs:

- Node/npm version check
- npm registry check
- `npm install`
- `npm run lint`
- `npm run build`
- `npm test -- --watchAll=false`
- `npm audit --audit-level=high`
- `npm ci --ignore-scripts`
- final production build

## Deployment

After the script passes:

1. Commit `frontend/package-lock.json`.
2. Change CI/deployment to use `npm ci`.
3. Deploy backend using `render.yaml`.
4. Configure MongoDB and Redis.
5. Configure AI/Razorpay/ElevenLabs secrets in Render.
6. Deploy frontend to Vercel.
7. Run the integration tests against the deployed API.

No source-level completion claim should be confused with live-service verification.
