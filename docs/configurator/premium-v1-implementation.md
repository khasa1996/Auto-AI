# Configurator Premium V1 Implementation Boundaries

## Implemented in this tranche

- backend-safe configured lead payload contract for finance/dealer handoffs
- purchasable-only configuration comparison contract
- share-card model that excludes private ownership data
- explicit capability flags for WebAR, mobile AR, configured video and live OEM inventory
- tests for the new contracts

## Next production integrations

1. Connect the lead payload to existing EMI, insurance, dealer enquiry and test-drive routes.
2. Add authenticated configuration history using the existing saved-configuration ownership model.
3. Add a two-build comparison UI backed by the comparison contract.
4. Add screenshot/share-card rendering from the share-card model.
5. Add asset-defined feature hotspot metadata and cinematic camera sequences.
6. Implement AI intent resolution only through backend option IDs and validation.
7. Add provider-neutral asset ingestion and admin publication workflow.

## Safety boundaries

- No price is calculated in the browser.
- No option ID is generated by AI or inferred from display text.
- No unverified 3D asset is published.
- No unsupported animation or AR behavior is simulated.
- Private ownership/authentication fields never enter public share-card data.
