# Auto AI India — Controlled Engineering Workflow

This directory contains approved designs, implementation plans and execution ledgers for major Auto AI India engineering work.

## Production release workflow

1. Review the design.
2. Explicitly approve the design.
3. Create and review the implementation plan.
4. Execute changes on an isolated release-candidate branch/worktree.
5. Test and review each task.
6. Perform a broad final review and production smoke test.
7. Request separate approval before merging/publishing to a shared production branch.

`main` remains the production baseline until the final release decision.
